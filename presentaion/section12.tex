% Slide 1: Concept
\begin{frame}{Tree Breadth First Search (BFS)}
  \begin{itemize}
    \item \textbf{The Core Idea:} Traverse a tree level-by-level, processing all nodes at depth $d$ before any node at depth $d+1$.
    \item \textbf{Implementation:} Typically implemented iteratively using a Queue (FIFO).
    \item \textbf{Common Triggers:}
      \begin{itemize}
        \item Level order traversals or printing.
        \item Finding the minimum depth of a tree.
        \item Tracking "level" boundaries (e.g. connecting next pointers).
        \item Finding the shortest path in unweighted graphs or state transitions.
      \end{itemize}
  \end{itemize}
\end{frame}

\begin{frame}{Level Size Strategy}
  To process nodes level by level rather than as a continuous queue stream:
  \begin{itemize}
    \item At the start of each level iteration, count the queue size: `val levelSize = queue.size`.
    \item Run a nested loop exactly `levelSize` times.
    \item Inside the loop:
      \begin{itemize}
        \item Pop a node from the queue.
        \item Enqueue its children (left, then right).
      \end{itemize}
    \item Any logic scoped to a level (e.g., calculating level average or reversing order) can be done cleanly.
  \end{itemize}
\end{frame}
