% Slide 1: Concept
\begin{frame}{What is the Prefix Sum Pattern?}
  \begin{itemize}
    \item \textbf{The Core Idea:} Precompute cumulative sums of an array: `prefix[i] = nums[0] + ... + nums[i]`.
    \item \textbf{Why it works:} Allows you to calculate the sum of any subarray `nums[i...j]` in $O(1)$ time:
      $$\text{Sum}(i, j) = \text{prefix}[j] - \text{prefix}[i-1]$$
  \end{itemize}
\end{frame}

\begin{frame}{Combining Prefix Sum with HashMap}
  To find subarrays summing to $K$ in $O(N)$ time:
  \begin{itemize}
    \item Maintain running cumulative sum `currentSum`.
    \item At each step, we look for a previous prefix sum that equals `currentSum - K`.
    \item Use a HashMap to store frequencies of prefix sums seen so far.
    \item \textbf{Key Modulo Trick:} For divisibility by $K$, store `currentSum % K` (handling negative mod values properly).
  \end{itemize}
\end{frame}
