% Slide 1: Concept
\begin{frame}{What is Modified Binary Search?}
  \begin{itemize}
    \item \textbf{The Core Idea:} An extension of standard binary search that applies to non-standard sorted structures or search spaces.
    \item \textbf{Why it works:} By dividing the search space in half in $O(1)$ time, we achieve a logarithmic $O(\log N)$ runtime.
  \end{itemize}
\end{frame}

\begin{frame}{Binary Search on Answer Space}
  Instead of searching indices in an array, we search value ranges (from `minPossibleAnswer` to `maxPossibleAnswer`):
  \begin{itemize}
    \item Find the midpoint `mid` of the current range.
    \item Run a validation function `isValid(mid)` to check if `mid` is a possible solution (usually in $O(N)$ time).
    \item Based on the result:
      \begin{itemize}
        \item If valid: Try to find a better solution in the lower half (if minimizing).
        \item If invalid: Discard the lower half and search the upper half.
      \end{itemize}
  \end{itemize}
\end{frame}
